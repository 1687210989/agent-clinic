## 指标明细

### E1 死循环 〔高〕

| 项 | 内容 |
|---|---|
| 数据来源 | `tool/call` + `tool/result` |
| 判定 | 同 `tool_name` + 同 `tool_args_hash` 复现，且配对结果均为错误 |
| 阈值 | ≥3 次 |
| 防误报 | **参数有变化的试错不计入**（哈希不同即不算） |
| 实测 | 已命中 `list_agents` 同参数重复 4 次 |

### E2 反复失败 〔中〕

| 项 | 内容 |
|---|---|
| 数据来源 | `tool/result` 的 `is_error` |
| 判定 | 会话工具错误率 = 错误数 / 工具调用数 |
| 阈值 | >30% |
| 实测基线 | 7.3%（4 会话）→ 当前应输出"未检测到异常" |

### C1 token 消耗过快 〔高〕（M2）

单会话 `output_tokens` 及日均值 vs **自身** 30 天中位数，超基线 50%。
**不做跨用户比较。**

### C2 上下文膨胀 〔高〕（M2）

末轮/首轮 `inputTokens` 比值 + `cacheReadTokens` 占比。
⚠️ 原阈值 `cache_read < 30%` 需重新标定 —— 实测占比 **93.9%**。

### A1 / A2 资产闲置 〔中〕（M2）

已配置 MCP / 已装 skill 在 30 天内 0 调用。
数据源：cordis 配置（`profiles/*/cordis.patch.yml`）、`~/.agents/skills/`。

## 误报防护规则（一票否决）

1. **可定位** —— 每个结论必须附 locator，不可复现的结论不出
2. **死循环豁免正常重试** —— 同参数 + 同错误 + ≥3 次
3. **软信号仅 K2** —— 措辞"疑似"，不给"高"严重度
4. **单样本不出结论** —— K1 需 ≥2 会话互证
5. **禁止硬编问题** —— 未检测到异常必须在报告中显式列出
6. **处方附置信度** —— 高/中两档
7. **处方须自证** —— 必须说明它如何解决对应信号
