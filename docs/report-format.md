# 体检报告输出格式

> 供 SKILL.md 与 `cli.mjs report` 使用。全部输出**中文**，风格紧凑。

---

## 模板

```markdown
## Agent 体检报告（平台：DSH · 近 30 天 · N 个会话）

扫描概览：N 会话 / N 行 / N 次工具调用 / 错误率 X%
token：input N · output N · cacheRead N

### 发现 K 个问题（按严重度排序）

**[高] E1 死循环** —— 会话 <id>，<tool> 同参数重复 N 次
- 证据定位：<file>#L<start>-L<end>
- 复核命令：node src/cli.mjs show "<file>#L<start>-L<end>"
- 影响估算：约 N 次无效调用
- 处方：<处方名>（<类型>）—— <它解决什么>
- 安装：<按平台生成的命令>
- 风险提示：<依赖 / 体积 / 冲突>
- 置信度：高

**[中] A1 MCP 闲置** —— <mcp 名> 已配置但 30 天 0 调用
- 处方：建议卸载（省磁盘与启动时间）
- 操作：编辑配置文件移除该条目（只给说明，不动手）

### 未检测到异常的维度
E2 反复失败（错误率 7.3%，低于 30% 阈值）、C1、C2、A1、A2……

### 未实现（骨架阶段）
C3、E3、E4、K1、K2、N1、N2、A3、A4
```

---

## 硬性要求

| # | 要求 |
|---|---|
| 1 | 每个结论必须带 **证据定位** 与 **复核命令** |
| 2 | 处方 **≤2 条**；无对症插件时诚实给"无插件可解，行为建议" |
| 3 | **必须**列出"未检测到异常的维度" —— 禁止只报问题不报正常 |
| 4 | 必须列出"未实现的维度" —— 让用户知道覆盖面，不假装全知 |
| 5 | 软信号（K2）措辞必须含"疑似"，且不得为"高"严重度 |
| 6 | 零对话原文；证据片段默认截断 400 字符 |
| 7 | 结尾注明数据完整性问题（坏帧 / 坏行 / 解析失败），如有 |

---

## 语气

- 直接，不客套
- 不确定就说不确定
- 不夸大影响（"约 1.8 万 token" 而非 "浪费了海量 token"）
- 没有问题时，明确说"未检测到异常"，而不是硬凑一条
